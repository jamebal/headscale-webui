# 部署值参数问号说明修复设计

## 问题

常规部署页重构后，布尔参数统一使用 `BooleanOption`，并通过 `help` 属性渲染 `HelpInfo`。需要先启用、再填写值的参数仍直接使用 `n-checkbox`，迁移时遗漏了 `HelpInfo`，因此页面没有显示问号说明。

受影响字段包括 `Operator`、`PreAuth Key`、`Hostname`、`Timeout`、`Accept Risk`、`Exit Node`、`Advertise Tags` 和 `Advertise Routes`。现有中英文说明文案仍然可用。

## 方案

保持现有状态、输入控件、校验与命令生成逻辑不变。每个受影响字段使用横向 `n-flex` 包裹启用复选框和 `HelpInfo`，并沿用原部署页中的对应命令说明与国际化文案。

不新增通用组件，避免为一次小范围展示修复引入额外抽象；布尔参数继续使用 `BooleanOption`。

## 测试

在部署页组件测试中验证每个受影响字段都向 `HelpInfo` 传入正确说明。测试先在当前实现上失败，再补充模板渲染并确认测试通过。

完成后运行部署页相关测试与 TypeScript 检查，并在实际部署页确认问号图标已生成。

## 非目标

- 不改变参数启用方式或默认值。
- 不改变命令生成、输入校验或国际化文案。
- 不调整部署页网格与响应式布局。
