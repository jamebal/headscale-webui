# 部署常用参数与个人节点恢复设计

## 背景

当前部署页用于生成 `tailscale up` 命令，已经覆盖基础连接、认证、DNS、路由、出口节点与标签等参数，但参数模型只有“选中或未选中”以及“非空字符串”两种状态。这导致页面无法表达 `--accept-dns=false` 等显式布尔值，也无法生成恢复标签节点所需的 `--advertise-tags=` 空值参数。

Headscale 将设置有效标签的个人节点转换为 `tagged-devices`。节点不能仅通过服务端清空标签恢复原用户身份，必须在客户端清空申请标签并强制重新认证。因此部署页需要提供清晰且安全的个人节点恢复场景。

## 目标

- 完善常用 `tailscale up` 参数，准确表达未指定、显式启用、显式禁用和显式空值。
- 提供从 `tagged-devices` 恢复为个人用户节点的引导和命令。
- 保持命令生成结果可复制、可预测，并对断连、配置重置和敏感行为给出明确警告。
- 通过纯函数和组件测试覆盖参数序列化与场景切换。

## 非目标

- 不支持 `--audience`、`--client-id`、`--client-secret` 和 `--id-token` 等 workload identity federation 参数。
- 不尝试由 WebUI 服务端直接完成客户端重新认证。
- 不读取或推断客户端当前的本地 Tailscale 设置。
- 不修改 Headscale 的节点标签 API 或身份模型。

## 页面结构

部署页增加场景选择，包含“常规部署”和“恢复个人节点”。默认进入“常规部署”。两个场景共用服务器地址、命令预览和复制能力，但使用各自独立的参数状态，避免切换场景时把恢复参数混入普通部署命令。

### 常规部署

保留现有参数分组，在此基础上：

- Boolean 参数使用“未指定、启用、禁用”三态控件。
- 字符串参数区分“未指定”和“已指定非空值”。
- 可清空字符串参数区分“未指定、非空值、显式空值”。
- `--accept-risk` 增加 `mac-app-connector`。
- 增加 `--netfilter-mode`，候选值为 `on`、`nodivert`、`off`。
- 增加 `--report-posture`、`--snat-subnet-routes` 和 `--stateful-filtering` 三态参数。
- 增加 `--json` Boolean 参数。
- 增加 `--qr-format`，候选值为 `auto`、`ascii`、`large`、`small`，仅在 `--qr` 启用时显示并参与命令生成。
- 修正 `--accept-routes` 默认值等帮助文案，使其与当前客户端帮助一致。

`--login-server` 继续由当前服务地址自动生成，不作为普通可选参数展示。

### 恢复个人节点

恢复场景默认生成：

```bash
tailscale up --login-server=<服务器地址> --advertise-tags= --force-reauth
```

页面同时展示以下说明：

- `--advertise-tags=` 用于显式清除申请标签。
- `--force-reauth` 可能中断当前 Tailscale SSH 或 RDP 会话，用户不得在唯一远程管理链路中贸然执行。
- 浏览器认证时必须登录准备恢复到的个人用户。
- 如果客户端报告存在未重新声明的非默认设置，用户应根据错误提示补齐这些设置。
- 成功后应通过节点列表确认所有者已从 `tagged-devices` 变为目标个人用户且标签为空。

恢复场景提供“重置其他设置”开关，默认关闭。启用后向命令加入 `--reset`，并显示醒目的风险提示：所有未在命令中声明的设置将恢复默认值，可能影响 DNS、路由、SSH、出口节点和防火墙行为。

## 参数模型与命令生成

将命令生成从 Vue 组件中提取为纯函数。参数状态分为：

```text
Boolean 参数：未指定 / true / false
普通字符串参数：未指定 / 非空值
可清空字符串参数：未指定 / 非空值 / 显式空值
```

序列化规则如下：

- 未指定参数不输出。
- Boolean `true` 输出 `--name`，Boolean `false` 输出 `--name=false`。
- 普通字符串输出 `--name=<value>`。
- 可清空字符串的显式空值输出 `--name=`。
- 参数值必须经过 Shell 安全转义，避免空格和特殊字符破坏复制后的命令结构。
- 输出顺序固定，确保测试稳定且用户容易比较命令变化。
- 条件参数失去依赖时自动回到未指定状态，例如关闭 `--qr` 后移除 `--qr-format`。

## 状态与数据流

用户选择场景后，页面初始化对应的参数状态。任何控件变化都会把结构化参数传入命令生成函数，生成函数返回完整命令字符串，命令预览和复制按钮只消费该字符串。

恢复场景不调用 Headscale 节点 API，也不在页面内假设目标用户。目标用户由客户端重新认证时的浏览器登录或 Headscale 注册审批决定。

## 错误与风险处理

- 必填的普通字符串为空时不生成参数，并在对应控件显示校验提示。
- 可清空字符串只有在用户明确选择“清空”时才输出空值，避免把尚未输入误判为清空。
- `--force-reauth` 附近固定显示断连警告。
- `--reset` 仅由用户主动启用，并在启用时显示配置重置范围。
- 复制成功沿用现有消息提示；剪贴板失败时显示明确错误，不宣称复制成功。

## 测试设计

纯函数测试覆盖：

- 参数未指定时不输出。
- Boolean `true` 与 `false` 的不同输出。
- `--advertise-tags=`、`--advertise-routes=` 和 `--exit-node=` 的显式空值。
- 参数值的 Shell 安全转义与固定顺序。
- 恢复场景默认命令不包含 `--reset`。
- 启用恢复场景的重置选项后生成 `--reset`。

组件测试覆盖：

- 两个场景切换时状态互不污染。
- `--qr-format` 的条件显示与清理。
- `--accept-risk` 包含 `mac-app-connector`。
- 恢复场景展示断连、重新登录和 `--reset` 风险提示。
- 常用新增参数能够进入命令预览。

现有 lint、类型检查和完整测试套件作为回归验证。

## 验收标准

- 部署页可以准确生成显式 `false` 和显式空值参数。
- 恢复场景默认生成包含 `--advertise-tags=`、`--force-reauth` 且不包含 `--reset` 的命令。
- 用户启用重置后，命令包含 `--reset`，页面同时显示风险警告。
- 常用新增参数与当前 `tailscale up` 帮助保持一致。
- 新增测试通过，现有功能和测试无回归。
